## ② 원인 — 실제 폰 크기로 재현 (Chromium 390×844)

9/3 **모바일 셸**(`refatrix-nav.js`)이 상단 바를 `z-index:9000`, 하단 탭바를 `9001` 로 올렸는데,

| 시트의 버튼 | 그 자리를 누르면 실제로 눌리는 것 (수정 전) |
|---|---|
| 새 미팅 **[미팅 계획 저장]** · [닫기] | **하단 탭바**(홈·고객·영업활동…) — 저장 버튼이 100% 가려짐 |
| 상세 **[✅ 미팅 완료]** · [삭제] (2번째 줄) | 하단 탭바 |
| 상세 [저장] · [✓ 약속 확정] (1번째 줄) | 겨우 보임 (폭·높이에 따라 가려짐) |
| 시트 제목 옆 **[✕]** | **[로그아웃]** ← 닫으려다 로그아웃되는 상태였다 |

8/26 검증은 모바일 셸 이전이라 통과했고, 9/3 모바일 셸 검증은 고객·견적 등 7화면만 봐서 이 시트를 못 잡았다.

## ③ 고친 것

### A. 시간표 08:00 → **21:00** (13칸)
- 새 전시회 기본 종료 시각 18 → **21** (백엔드 `DEFAULT_END_HOUR` · 화면 `EX_DEF_END` · DB 기본값).
- **0215** 가 지금 18시로 등록된 전시회(RUJAC)를 21시로 늘린다. **18이 아닌 값(디렉터가 ⚙ 에서 직접 고른 19·20·22시)은 안 건드린다.**
- 이미 걸린 미팅은 칸(day × hour)이 그대로라 영향 없음 — 저녁 칸 3개(18·19·20시)가 늘기만 한다.
- ⚙ 설정의 종료 시각 선택지를 13~22 → **13~23** 시로.
- 참고: 0215 를 돌리기 전에도 디렉터가 **⚙ 전시회 설정 → 종료 시각 21:00 → 설정 저장**으로 즉시 바꿀 수 있다(그 기능은 원래 있었다).

### B. 폰에서 저장 버튼 — 가려지지 않게
- 시트 `z-index` 70 → **10001** (뒷막 10000, 토스트 10020). 모바일 셸 위로 올라와 **전체화면 작업 모드**가 된다.
  nav.js 의 전역 팝업(승인대기 등, 10050)은 여전히 시트보다 위.
- 넓은 화면(≥1100px) 오른쪽 패널은 그대로 문서 흐름 안(`z-index:1`)이고, 대신 **고정 헤더 높이만큼 아래**(`--ex-navh`)에 붙는다.
  예전엔 `top:14px` 이라 스크롤하면 패널 윗부분이 헤더 밑으로 들어갔다. 패널을 열 때 버튼줄이 화면 밖이면 그만큼 자동으로 내려 준다.
- `touch-action:none` 을 html/body 에서 **뒷막으로만** 옮겼다 — iOS 에서 시트 안 스크롤까지 막을 수 있는 설정이었다.

### C. 저장 플로우 (「플로우를 고려해서」)

**신규 (신규확정)**
1. 빈 칸(예: 20:00) 탭 → 전체화면 시트.
2. 맨 위 **「📌 종류 · 확정」**: [🤝 고객 약속 / 🚶 부스 방문] + **☑ 고객이 이 약속을 확정했습니다** + ☐ 즉석.
   (예전엔 확정 체크가 고객 입력칸들 아래 묻혀 있었다 → 「무슨 미팅인가」를 먼저 정하도록 위로 올림)
3. 하단 큰 버튼 문구가 **지금 무엇을 저장하는지** 말한다:
   `💾 미팅 계획 저장` / **`✓ 확정 미팅으로 저장`** / `🚶 부스 방문 저장` / `🎙 등록하고 바로 녹음`
4. 저장 → 그 미팅 **상세로 바로 전환** + 버튼에 `✓ 확정 미팅 저장됨` → 다음 할 일(녹음·확정·완료)이 같은 자리에 있다.

**수정 (수정확정)**
1. 칩 탭 → 상세. 하단 1줄 **[💾 저장]**(크게), 2줄 [✓ 약속 확정] [✅ 미팅 완료] [삭제](작게).
2. 무엇이든 입력하면 저장 버튼이 **금색 `💾 변경 저장`** 으로 바뀐다 → "아직 저장 안 됨"이 한눈에.
3. 저장 → 시트는 **열린 채**, 버튼 `✓ 저장됨`, **보던 위치 유지**(메모칸에서 저장해도 맨 위로 안 튐).
4. 입력 중에 **[✓ 약속 확정] / [✅ 미팅 완료]** 를 누르면 **입력값까지 함께 저장**한다.
   (예전엔 그 필드만 PATCH 하고 화면을 다시 그려서, 쓰던 메모·목표가 **조용히 사라졌다**)
5. 저장 안 하고 ✕ / 뒷막 / Esc / [닫기] → **「저장하지 않고 닫을까요?」** 확인. 변경이 없으면 묻지 않는다.
6. **🤖 정성목표 달성 판단**을 누를 때 저장 안 한 정성목표가 있으면 **먼저 저장하고** 판단한다(서버는 저장된 목표로 판단하므로).

**키보드**
- 폰 키보드가 올라오면 시트를 **보이는 영역(visualViewport)에 맞춰** 줄이고, 보조 버튼은 접어 **[저장] 하나만 키보드 바로 위에** 남긴다. 키보드가 내려가면 원래대로.

**기타**
- 토스트: 시트가 열려 있으면 **위쪽**(헤더 아래)에 떠서 저장 버튼을 가리지 않는다. 시트가 닫혀 있으면 하단 탭바 위.
- 체크박스가 `.ex-sec input{width:100%}` 에 먹혀 **반 폭으로 늘어나던** 것 수정(22px).
- 업체명이 비어 저장이 막히면 그 칸으로 스크롤 + 포커스.
