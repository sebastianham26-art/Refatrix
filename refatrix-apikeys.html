① 외부 서비스 API 키
빈칸 = 지금 값을 그대로 둡니다. 바꿀 때만 새 값을 넣으세요. - 한 글자만 넣고 저장하면 그 값을 지우고 Railway 환경변수 값으로 되돌립니다.
저장된 비밀키는 화면으로 다시 내려오지 않습니다(앞 4자·뒤 4자만 확인용으로 표시). 저장 즉시 서버에 반영되며 재배포는 필요 없습니다.
② CRM 연동 키 (웹카달록) 주소·계약서·전송이력은 연동 관리에서
CRM 연동 키는 연동 등록부(integration_endpoints)에 그대로 보관됩니다 — 여기서는 키만 바꿉니다. 같은 규칙: 빈칸 = 유지 · - = 지움. 수신 연동(우리가 발급한 키)은 연동 관리 화면에서 재발급하세요.
③ 키 변경 이력 값은 기록하지 않습니다 — 무엇을 언제 누가 바꿨는지만
