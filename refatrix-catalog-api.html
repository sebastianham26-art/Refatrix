고객사 목록
키 1개 = 고객사 1곳 = ERP 고객 마스터 1행. 구매단가는 조회가 들어온 그 순간 고객 마스터의 할인율로 계산된다 — 마스터의 할인율을 바꾸면 다음 호출부터 바뀐 가격이 나간다. 여기에 가격을 따로 저장하지 않는다.
고객사 설정
접속창
멕시코 중부시간(UTC−6, 서머타임 없음) 기준이다. 종료 시각은 미만이다 — 09 를 넣으면 08:59:59 까지 열린다. 테스트 키는 접속창을 적용받지 않는다(개발자가 평일에 붙어 볼 수 있어야 한다).
대응품번 출처는 기본이 제품찾기 화면과 같은 값(products.scode · 전부 SYD)이다. 「교차참조표」는 역매칭용으로 쌓은 다른 표라 BAW·GROB·MOOG 등이 섞여 있고 화면과 목록이 다르다.
제외할 코드 접두어에 적은 것으로 시작하는 제품은 목록에도, 단건 조회에도 나오지 않는다 (기본 PRO). 비우면 전부 나간다.
재고 표기는 기본이 구간이다("existencia": "21-50"). 「수량 그대로」로 바꾸면 숫자가 나가는데, 그때 필드 타입이 문자열에서 숫자로 바뀐다 — 이미 연동 중인 고객사가 있으면 개발자에게 먼저 알려야 한다.
