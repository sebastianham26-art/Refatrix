## ① 요청

> RUJAC에서 미팅을 완료했고 미팅내용이 기록되거나 녹음 요약이 한 번 되었으면 **상시보기**로.
> 지금은 이미 녹음이 되었거나 미팅요약기록이 있는데도 **보이지 않거나 눌러야 보이는** 방식.

## ② 원인

1. **보드 데이터에는 요약이 이미 실려 있었는데 화면이 안 그렸다.** `/board` 가 미팅마다 `summary` 를 내려주지만,
   상세 시트는 `🎙 녹음 · AI 요약 열기` 를 눌러 녹음 카드를 끌어와야만 요약을 보여 줬다. 칩에는 아예 없었다.
2. **녹음이 여러 건이면 마지막 1건만** 내려왔다(두 번 녹음 · 4시간 초과 자동 분리 · 음성 메모).
3. **「보이지 않던」 실제 버그** — 녹음 카드를 시트에 열어 둔 채 **[저장] · [미팅 완료] · [정성목표 판단]** 을 누르면
   시트를 새로 그리면서 녹음 카드(`#cs-recCard`)가 **DOM 에서 떨어져 나가 사라졌다.** 그 뒤로는 페이지를 새로고침하기 전까지
   요약 카드도, 일반 고객상담의 녹음 카드도 없는 상태가 됐다.

## ③ 바뀐 것

### 시간표 칩 (누르지 않아도)
- 완료했거나 요약이 있는 미팅은 칩 아래에 **두 줄 요약**이 늘 보인다.
  - `🎙 El cliente pide 10 muestras…` — 가장 최근 녹음 요약
  - 녹음 없이 완료 + 메모만 있으면 `📝 재방문 약속, 카탈로그 전달함`
  - 요약 대기 중이면 `⏳ AI 요약 중…`
- 계획 단계의 사전 메모만 있는 미팅은 표시하지 않는다(요청 조건: 완료했거나 요약이 된 것).
- 🔒 감춘 상담은 칩에도 아무것도 안 나온다(기존 가시성 규칙 그대로).

### 상세 시트 맨 위 「📋 미팅 기록」 (펼친 채로)
- **📝 현장 메모** + **요약된 녹음 전부**(최근 것이 위, 녹음 길이·음성 메모 표시) — 요약 · 카테고리별 핵심 · 파악 · 펜딩(기한) · 언급 제품 · 다음.
- `🎙` 를 누를 필요 없음. 버튼은 요약이 있으면 `🎙 추가 녹음 · 전사 원문` 으로 바뀐다.
- 요약 대기 중이면 「⏳ 녹음 N건 AI 요약 중 — 끝나면 여기에 자동으로 붙습니다」.

### 자동 갱신
- 요약을 기다리는 녹음이 있거나 시트에서 녹음 카드를 열어 둔 동안 **20초마다 보드를 조용히 다시 읽는다**
  (화면 깜빡임 없음 · 보던 날짜 탭 유지 · 탭이 백그라운드면 쉼). 요약이 끝나면 칩과 기록 칸에 **새로고침 없이** 붙는다.
- 기록 칸만 갈아 끼우므로 **입력 중인 값·녹음 카드는 건드리지 않는다.**

### 🇰🇷 요약 한국어
- 툴바 `🇰🇷 요약 한국어` (기록 칸 안에도 같은 버튼) — 칩과 기록 칸을 한 번에 한국어로. 번역본이 없는 요약만 서버에 요청(서버 캐시 재사용).
  선택은 브라우저에 기억된다.

### 녹음 카드 보호 (버그 수정)
- 같은 미팅을 다시 그릴 때는 카드를 잠시 제자리로 옮겼다가 **새 시트에 다시 붙인다.**
- 녹음 중에 다른 미팅 · 새 미팅 · 설정으로 넘어가려 하면 「녹음 중입니다 — 먼저 ⏹ 녹음 종료」 로 막는다.

### 백엔드
- `buildBoard` 가 미팅마다 **`recs`**(요약된 녹음 전부: id · mode · duration_sec · processed_at · summary)와
  **`rec_pending`**(queued/transcribing/summarizing 건수)를 추가로 내린다. 기존 `summary`/`rec_id` 는 호환용으로 그대로(최근 1건).
  감춘 상담이면 `recs=[]`, `rec_pending=0`.

## ⑤ 현장 테스트

1. 녹음·요약이 끝난 RUJAC 미팅 → 시간표 칩에 두 줄 요약이 보이는지(누르지 않고).
2. 그 칩 탭 → 시트 맨 위 📋 미팅 기록에 메모 + 요약 전문이 **펼쳐져** 있는지.
3. 녹음 없이 메모만 쓰고 `✅ 미팅 완료` → 칩에 `📝 메모`.
4. 새 녹음 업로드 → 칩 `⏳ AI 요약 중…` → 1~3분 뒤 **새로고침 없이** 요약으로 바뀌는지.
5. 녹음 카드를 연 채 메모 입력 → `💾 저장` → 녹음 카드가 **그대로 남는지**(예전엔 사라짐).
6. `🇰🇷 요약 한국어` → 칩·기록 칸이 한국어로, 다시 누르면 원문.
7. 영업사원 계정에서 🔒 감춘 상담 미팅 → 요약 안 보이는지.
