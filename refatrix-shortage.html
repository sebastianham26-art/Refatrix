Offer Sheet — 부족분 입고 알림·재오퍼 (고객별)
부족분으로 남았던 제품이 입고(수입입고 승인 → 재고 등재)되면 자동으로 고객별 오퍼 시트가 만들어집니다. 대상: ① 전환확정(인보이스 발행)·매출등록·견적만료 시 기록된 부족분 + ② 견적서의 부족 라인(최초 견적 부족분 — 전환 전 견적 및 최근 90일 내 만료 견적 포함). [스캔·생성]은 지금 재고가 있는 대기 수요 전체를 다시 훑어 누락분을 만듭니다(중복 생성 안 됨). 시트를 열어 📲 WhatsApp 자동발송(버튼 한 번, 발송 이력 자동 기록) 또는 PDF 출력 → 💚 수동 전송 → 발송완료 처리로 보내세요.
더 이상 내보내지 않을 오퍼는 시트를 열어 🚫 비활성화 — 부족 기록은 그대로 남고(발주 근거) 그 오퍼만 다시 생성되지 않습니다(디렉터·Maria, 되돌리기 가능). ✖ 취소는 반대로 다시 생성 대상으로 복귀시킵니다.
📲 WhatsApp 자동발송 설정 방법 (토큰 발급 — 클릭 단위 안내)
준비물: Facebook 계정 · 회사용 전화번호 1개(기존 WhatsApp 앱에서 사용 중이지 않은 번호 권장)
① Meta 개발자 앱 만들기 — developers.facebook.com 접속 → 우상단 [My Apps] → [Create App] → 유형 Business 선택 → 앱 이름(예: Refatrix) 입력 → [Create App]
② WhatsApp 추가 — 앱 대시보드에서 WhatsApp 카드의 [Set up] 클릭 → 비즈니스 포트폴리오 선택(없으면 새로 만들기)
③ 발신번호 등록 — 좌측 WhatsApp → API Setup → [Add phone number] → 회사 번호 입력·SMS 인증 → 화면의 Phone number ID 를 복사 → Railway 변수 WHATSAPP_PHONE_ID
④ 영구 토큰 발급 — business.facebook.com → 설정(Business Settings) → 사용자 → 시스템 사용자 → [추가](이름 예: refatrix-bot, 역할 관리자) → [자산 추가]에서 위 앱 선택(전체 제어) → [토큰 생성] → 앱 선택 → 만료 없음 → 권한 whatsapp_business_messaging + whatsapp_business_management 체크 → 생성된 토큰 복사 → Railway 변수 WHATSAPP_TOKEN (API Setup 화면의 임시 토큰은 24시간만 유효 — 반드시 시스템 사용자 영구 토큰 사용)
⑤ Railway 등록 — Railway → 서비스 → Variables 에 WHATSAPP_TOKEN·WHATSAPP_PHONE_ID 저장 → 자동 재배포 후 이 화면 새로고침 → 📲 버튼 활성
⑥ (권장) 템플릿 승인 — business.facebook.com → WhatsApp Manager → 메시지 템플릿 → 템플릿 만들기 → 카테고리 유틸리티 · 언어 스페인어(MEX) · 본문에 {{1}} 하나만 넣고 제출 → 승인(수 분~수 시간) 후 템플릿 이름을 Railway 변수 OFFERSHEET_WA_TEMPLATE 에 저장. 고객이 24시간 내 회신한 적 없어도 헤드라인 요약이 도달합니다.
참고: 발신번호 미보유 시 API Setup 의 테스트 번호로 먼저 검증 가능(수신자 5명 제한). 오늘 요약 05시 자동 보고와 같은 토큰을 공유합니다.
