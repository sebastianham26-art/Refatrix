# 검수 개편(build 20260817r) 배포 순서 — 반드시 이 순서대로

"스캔은 기록, 판정은 보고서" 개편 + **이중 스캔 기록 수정**입니다.
스캔 시점 판정·차단이 전부 사라지고, 모든 스캔이 즉시 서버(inbound_scans)에 저장되며,
스캔마다 고유 키가 붙어 전송이 재시도돼도 **정확히 1회만** 기록됩니다(0175).
적치 화면에는 **✎ 수정 기능**(이미 올린 박스의 위치 변경·빼기)이 추가됐습니다.
그리고 **검수 완료 → 적치 전 입고**가 가능합니다: 마감(입고)이 실측 스캔 수량으로
구매에 반영되고, 적치는 마감 후에도 계속 진행됩니다(판매 대응 앞당김).
**백엔드 먼저** 배포해야 합니다.

## 이중 스캔이 이미 기록된 팔렛 정리

이미 2회로 잡힌 스캔은 집계표의 [−] 버튼으로 한 건 빼면 됩니다(서버에서도 취소됨).
여러 팔렛이 엉켰으면 [🧹 검수 리셋] 후 다시 스캔하세요.

## ③ 26B2C 선적 정리 (디렉터 계정, 딱 한 번)

1. 선적 열기 → 상단 **[🧹 검수 리셋]** → 확인
   (잘못 저장된 검수·적치·스캔이 초기화됩니다. 기록은 감사용으로 보존)
2. **[🔀 라인 재분할]** → 원본 패킹리스트 선택
   (CARTON UNIT × QTY PER C/T 기준으로 카톤 수가 교정됩니다)
3. 검수 탭에서 새 방식으로 작업 시작

## ④ 새 검수 절차 (작업자)

1. **팔렛 선택** — 칩을 눌러 지금 작업할 팔렛을 고른다 (시스템 추측 없음)
2. **전부 스캔** — 어떤 경우에도 막지 않는다. 스캔마다 존이 크게 표시되고
   즉시 서버에 저장된다 (배너에 ● 서버 저장됨 / 전송 대기 표시)
3. **[📋 대조]** — 서버가 패킹리스트와 비교한 예상/스캔/차이 보고서
4. **[✔ 입고 확정]** — 실제 스캔 수 그대로 저장. 차이가 있어도 확정 가능,
   부족분은 나중에 더 스캔하고 재확정하면 된다

오스캔은 집계표의 [−] 버튼으로 빼면 서버에서도 최근 1건이 취소됩니다.
네트워크가 끊겨도 스캔은 큐에 남아 자동 재전송됩니다(새로고침에도 보존).

## 적치 수정 사용법 (build p)

적치 작업 화면의 SKU 줄마다 ✎ 버튼이 있습니다. 누르면:
- **[−1 빼기]** — 랙에서 내린 박스만큼 누르면 적치 수량이 줄어듭니다(서버 반영, 0 밑으로 안 내려감)
- **[+1 추가]** — 스캔 없이 수동으로 1개 추가
- **[위치 적용]** — 새 랙을 스캔/입력하면 이 선적의 적치 위치가 바뀝니다.
  "제품 기본 위치도 변경" 체크(기본 켜짐) 시 제품 마스터 위치도 함께 갱신되고 감사로그에 남습니다.
변경은 2.5초 후 자동 저장되며 [✔ 적치 저장]으로 즉시 저장할 수도 있습니다.

## 검수 후 바로 입고 (build r)

적치를 기다릴 필요 없이, **모든 팔렛 검수가 끝나면 [마감] 탭에서 바로 입고**할 수 있습니다.
- 마감 수량은 이제 패킹리스트 예상이 아니라 **실측 스캔 수량**(부족/초과 그대로)으로 구매 received_qty 에 반영됩니다.
- 마감 후에도 적치 탭은 그대로 사용 가능합니다 — 판매 대응과 적치를 병행하세요.
- 미검수 팔렛이 있으면 그 팔렛은 이번 입고에서 제외된다는 경고가 표시됩니다.
- 마지막 팔렛 검수를 확정하면 "지금 바로 입고 가능" 안내가 자동으로 뜹니다.
