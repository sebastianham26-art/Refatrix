## 무엇이 바뀌나

### ① 화면이 멈추던 문제 (버그)
- 상세 시트를 열면 뒤 화면을 잠그는데, **닫아도·모드를 바꿔도 잠금이 안 풀려** 스크롤이 죽어 있었습니다.
  이제 닫기·뒷막 클릭·모드 전환·`Esc`·창 크기 변경 어디서든 **반드시 풀립니다**.
- 창 너비 **761~1099px**(작게 띄운 데스크탑 창·태블릿)에서 시트가 화면 전체를 덮어
  페이지가 사라진 것처럼 보였습니다. 이제 **가운데 모달 카드 + 어두운 뒷막**으로 뜹니다.
- 뒷막을 누르면 닫힙니다. 폰에서는 지금처럼 전체 화면 시트입니다.

### ② 약속 확정(컨펌)
- 미팅 계획을 먼저 넣고, 고객이 확정하면 **[✓ 약속 확정]** 을 누릅니다.
- 시간표에서 **미확정 = 점선 테두리 + `확정대기`**, **확정 = 실선 + `확정 ✓`** 로 한눈에 갈립니다.
- 상단 KPI 에 **`약속 확정 3 / 5`** 와 `확정 대기 2` 가 나옵니다.

### ③ 부스 직접 방문
- 약속 없이 고객 부스를 찾아가는 영업 시간도 슬롯에 넣습니다.
- 등록할 때 **[🤝 고객 약속] / [🚶 부스 방문]** 중에 고릅니다.
- 부스 방문은 담당자 색을 쓰지 않고 **공통 회색**으로 표시되고, **담당자 이름**이 함께 붙습니다.
- 범례에 `🚶 부스 방문 N` 칩이 따로 생기고, 누르면 부스 방문만 강조됩니다.
- 담당자별 표에 `3건 (부스 1)` 처럼 부스 건수가 같이 나옵니다.

## 테스트

1. 🎪 전시회 → 빈 칸 클릭 → **[🤝 고객 약속]** 으로 미팅 등록(확정 체크 안 함)
   → 시간표에 **점선 + `확정대기`** 로 뜨는지.
2. 그 미팅을 열어 **[✓ 약속 확정]** → 실선 + `확정 ✓` 로 바뀌고 KPI 숫자가 오르는지.
3. 빈 칸 클릭 → **[🚶 부스 방문]** 선택 → 부스 이름 입력 → 저장
   → **회색 칩 + 담당자 이름**으로 뜨는지. 확정·즉석 체크칸이 사라지는지.
4. 범례의 `🚶 부스 방문` 을 눌러 부스만 강조되는지.
5. **스크롤**: 시트를 열었다 닫고 페이지가 정상적으로 스크롤되는지.
   시트를 **연 채로 [🧾 일반 고객상담]** 으로 넘어가도 스크롤이 되는지. (이게 이번 버그였습니다)
6. 브라우저 창을 **1000px 정도로 줄여서** 미팅을 열어보기 → 가운데 모달로 뜨는지, 뒷막을 누르면 닫히는지.
7. 폰에서 1~6 반복.
