# 카탈로그 조회 API — 재고 0 을 「1-3」으로 보내기 · 2026-10-13 (rev. 0273)

## 무엇을 하는가
고객(CIOSA)에게 나가는 `existencia` 에서 **재고가 0 인 제품만** `1-3` 으로 바꿔 보낸다.

- 고객은 소량이 있다고 보고 주문을 넣는다 → **그 주문이 곧 이 고객의 결품 수요**다.
- 사내 약속: 고객 쪽에 **`1-3` 으로 보이는 제품 = 실제 재고 0**.
- 실재고 1~5 개인 제품은 종전대로 **`1-5`** 로 나간다. 두 값은 **절대 섞이지 않는다.**
- 나머지 구간(6-10 · 11-20 · 21-50 · 51-100 · 101+)은 그대로다.
- 수량 모드(숫자)로 설정된 고객이면 0 → **2** 로 나간다.

## 켜고 끄기
연동관리 → 카탈로그 조회 API → 고객사 **설정** → **「재고 0 인 제품」**

- `있는 그대로 0 으로 보낸다` (기본, 종전과 같음)
- `1-3 으로 보낸다 — 주문을 받아 결품 수요를 본다`

고객사별 설정이라 다른 고객에게는 영향이 없다. 언제든 되돌릴 수 있다.

## 어디서 확인하나
- 설정 화면 미리보기: 「재고 0 → 1-3 (사내 약속: 결품)」 표시
- **엑셀 다운로드 → 설정·요약** 시트: 「재고 0 인 제품 … 1-3 으로 보냄 (N건)」 — 지금 몇 건이 그렇게 나가는지 바로 보인다
- 고객 주문이 들어오면 ERP 견적·매출로 잡히고, 재고가 0 인 품목이므로 **기존 재고부족·발주 계산에 그대로 반영**된다
