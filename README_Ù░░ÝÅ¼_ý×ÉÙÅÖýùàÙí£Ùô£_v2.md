※ 전시회 기능(v1)은 이미 배포되어 있습니다. 이 zip은 그 위에 덮어씁니다.

## 무엇이 바뀌나

- **⏹ 녹음 종료를 누르면 자동으로 업로드되고 AI 요약까지 이어집니다.** 버튼을 따로 누를 필요가 없습니다.
  (5초 미만 녹음만 실수로 보고 자동 업로드하지 않습니다 — 필요하면 `↻ 다시 업로드`)
- **녹음을 3MB 조각으로 나눠 보냅니다.** 한 시간짜리 미팅도 안전하고, 조각마다 자동 재시도합니다.
  진행 상황이 `⬆ 업로드 중… 4 / 7 조각 (57%)` 로 보입니다.
- **실패하면 이유를 구분해서 알려줍니다** — 예전엔 뭐가 터져도 "서버 연결 실패" 하나였습니다.
  · `녹음을 파일로 바꾸지 못했습니다` (기기 메모리)
  · `전송이 끊겼습니다 (3/7 조각 완료)` (통신)
  · `서버가 거절했습니다 — … (코드 413)` (서버)
  어느 경우든 **녹음 내용은 브라우저에 남아** `↻ 다시 업로드`로 재시도할 수 있습니다.

## 순서대로 하시면 됩니다

1. `refatrix_자동업로드_v2.zip` 을 **repo 최상위**에 풀어 덮어쓰기.
2. GitHub Desktop → **Commit → Push** → Railway 재배포 **Success** 확인.
3. Railway **APP Console** 에서 **`npm run migrate`** 실행 (0185 적용).
4. **Ctrl+Shift+R** (폰은 브라우저 캐시 삭제) → 고객상담 화면 새로고침.

> **3번을 깜빡해도 녹음은 됩니다.** 서버가 `migration_required` 를 돌려주면 화면이 자동으로
> 예전 방식(한 번에 전송)으로 되돌아갑니다. 다만 큰 녹음은 여전히 실패할 수 있으니 migrate 는 꼭 해주세요.

## 테스트

1. 고객상담 저장 → 🎙 카드에서 `● 미팅 녹음` → **10초 이상** 말하고 `⏹ 녹음 종료`
   → **버튼을 누르지 않아도** `⬆ 업로드 중… 1/1 조각` → `✔ 업로드 완료` 가 떠야 합니다.
2. 1~3분 뒤 `✅ 완료` + 요약·카테고리 불릿·펜딩이 뜨는지.
3. 3초만 녹음하고 종료 → `너무 짧아 자동 업로드하지 않았습니다` 안내가 뜨는지.
4. 전시회 미팅에서도 같은지 (🎪 → 미팅 → 🎙 → 녹음 → 종료 → 자동 업로드).
5. 긴 녹음(가능하면 10분 이상) → 조각이 여러 개로 나뉘어 올라가는지 (`3 / 5 조각` 식 표시).
